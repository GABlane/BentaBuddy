# Hackathon disclosures

- Product: BentaBuddy, a local AI bakery order manager.
- Application implementation: created during this hackathon workspace session. No earlier study-app code is used in the final product. Review the repository history and team contributions before making any event submission claim.
- AI-assisted development: OpenAI Codex assisted with research, product planning, application code, styling, documentation, and tests. Earlier brainstorming used Codex agents. Codex is a development tool; the product does not call OpenAI or other cloud AI APIs.
- Product model: pretrained Qwen3 4B, quantized GGUF distributed as Ollama `qwen3:4b-instruct-2507-q4_K_M`; no original training or fine-tuning claimed. Model license: Apache 2.0. Source: https://ollama.com/library/qwen3:4b-instruct-2507-q4_K_M and https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507.

- Core dependencies: React, Vite, TypeScript, Lucide icons, FastAPI, Pydantic, Uvicorn, HTTPX, SQLite. Exact dependency versions are in package-lock.json and requirements.lock.txt; dependency licenses remain with their distributions.

Image generation is not called by the running app.

Separately, three real local CPU Instruct-model generations passed through the application validation and approval code using a CLI transport substitute. See AI_VALIDATION.md for scope and actual timings. Running-server HTTP transport and browser behavior still require verification after restart.
